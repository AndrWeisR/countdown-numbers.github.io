**Countdown Numbers** is an Android mathematical puzzle game.
Play Countdown number puzzles against the clock, or let the app find solutions to puzzles you set up. Countdown number puzzles require you to work out a sequence of calculations with six numbers whose final result is as close to a random target number as possible.
The application uses Google Play Games Services to provide features such as player sign-in and leaderboards.

**Privacy Policy**
The Countdown Numbers app does not collect any information about the user.
